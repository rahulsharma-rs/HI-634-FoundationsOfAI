# Chapter 4 Teaching Map

| Chapter concept | Notebook section | Observable learner outcome |
|---|---|---|
| Decision-centered formulation | 1 and 2 | Specify user, prediction time, target, action, comparator, and error consequences for a proposed model |
| Learning paradigms and task families | 2 | Match health-service questions to supervised, unsupervised, semi-supervised, or self-supervised learning and to classification, regression, ranking, clustering, or anomaly detection |
| Data inspection and label definition | 3 | Verify the unit of analysis, feature types, missingness, duplicates, target encoding, and prevalence |
| Leakage-safe partitioning and preprocessing | 4 | Create stratified development, validation, and test sets and fit learned transformations only on training data |
| Baselines and binary metrics | 5 | Compare a prevalence baseline and logistic pipeline using metrics tied to false-positive and false-negative consequences |
| Calibration, thresholds, and ranking | 6 | Evaluate probability quality and choose an operating point or queue size on validation data |
| Model comparison and final evaluation | 7 | Compare complete pipelines with identical folds and evaluate one locked model on an untouched test set |
| Interpretation | 8 | Explain coefficients and permutation importance as model summaries, not causal effects |
| Unsupervised learning | 9 | Scale features, compare K-means solutions, and state why a silhouette score does not validate patient types |
| Regression | 10 | Compare MAE, RMSE, and R-squared while interpreting error in days |
| Anomaly detection | 11 | Use anomaly scores for review prioritization without treating unusualness as wrongdoing |
| Evaluation, Responsible AI, Secure AI | 12 | Perform a release-readiness critique that includes validity, fairness, privacy, integrity, human authority, monitoring, rollback, and retirement |
| Retrieval and transfer | 13 | Answer review questions and complete extensions that modify assumptions rather than only rerun code |

## Suggested 120-minute pacing

- 0-15 minutes: framing, learning paradigms, and task selection.
- 15-30 minutes: dataset provenance and inspection.
- 30-50 minutes: partitioning, preprocessing, and leakage.
- 50-75 minutes: baselines, metrics, calibration, thresholds, and capacity.
- 75-90 minutes: model comparison, locked evaluation, and interpretation.
- 90-108 minutes: clustering, regression, and anomaly-detection contrasts.
- 108-120 minutes: Evaluation, Responsible AI, Secure AI, and exit ticket.
